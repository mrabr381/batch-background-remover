✂️ Batch Background Remover — Sample Report

Free, local batch background removal with rembg (U2-Net). No upload, no per-image fee, no API key. This page shows the real measured results of the bundled sample run — 3 product-like images, cleaned on CPU.

Real photo test — not a drawing

A real product photo: a red enamel mug on a plain white background, photo by Andreea Ch on Pexels (Pexels License — free to use), 1200×800, cleaned on CPU with U2-Net, verified 2026-11-20. 95.81% transparent, 0.61% edge, 3.57% product kept. All four corners measure alpha 0; the product centre (middle of bounding box [716, 439, 995, 648]) measures alpha 254. The photo is a binary JPG, so it is not in this repo — download it and reproduce the run:

curl -L -o red-mug.jpg "https://images.pexels.com/photos/3961751/pexels-photo-3961751.jpeg?auto=compress&cs=tinysrgb&w=1200"
python -m bgremove --input folder-with-red-mug.jpg --out clean/

Full measured stats: real_photo_stats.json.

Try it yourself

git clone https://github.com/mrabr381/batch-background-remover.git
cd batch-background-remover
python -m venv .venv && .venv/bin/pip install -r requirements.txt
python scripts/make_sample.py          # recreate the 3 sample images
.venv/bin/python -m bgremove --input sample_data --out clean/

First run downloads the U2-Net model once (~176 MB) into ~/.u2net; after that the tool works fully offline. Or use the web UI: streamlit run app.py — upload images, preview before/after, download a ZIP.

The three images above are simple PIL-drawn product shapes on plain backgrounds — the offline test fixture, not the demo. The real-photo test above them is a genuine photograph. Source: github.com/mrabr381/batch-background-remover

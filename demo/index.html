✂️ Batch Background Remover — in-browser demo

Try background removal without installing anything. Two ways, labelled honestly:

1. Instant demo (below, first): the real red-mug product photo with a precomputed mask — made by this repo's own Python CLI (rembg + U2-Net). No model runs in your browser for this photo; you just adjust the threshold and background and see the real result live.
2. Live AI (below, second): upload your own photo and a real 44 MB segmentation model (Silueta) runs in your browser with onnxruntime-web. Your photo never leaves your computer. First use downloads the model once.

Full power (batch folders, U2-Net 176 MB model, alpha matting, reports) lives in the Python CLI on GitHub. No API key, nothing uploaded, anywhere on this page.

1. Instant demo — red mug, precomputed mask

Real product photo: red enamel mug on white, by Andreea Ch on Pexels (Pexels License). The mask was computed by the Python CLI (U2-Net) and is stored in the repo as text — measured on the full 1200×800 photo: 95.81% transparent · 0.61% edge · 3.57% product kept, all four corners alpha 0, product centre alpha 254. (full stats)

Background:

Press “Load the red-mug demo”.

2. Your photo — live AI in your browser (experimental)

This runs the real Silueta segmentation model (rembg, 44 MB) in your browser via onnxruntime-web 1.20.1 (both from CDNs — nothing is installed). The model file is the official rembg release, mirrored on Hugging Face and checksum-verified (md5 55e59e0d8062d2f5d013f4725ee84782). Works best on product shots and people against a plain background; hair, glass and busy backgrounds are hard — same honest limits as the CLI.

Background:

Pick a photo, then press “Remove background”.

Verification: the model was run on this same mug photo with Python onnxruntime (95.89% transparent · 0.80% edge · 3.31% product) and with onnxruntime-web in Node — the two masks are identical (mean abs. difference 0.000000). Browser execution itself is exercised by this page; if the model fails to start here, the page says so instead of faking a result.

Photo: Andreea Ch, Pexels. Model: Silueta via rembg (MIT). Runtime: onnxruntime-web (MIT). Demo is static HTML + JS only — no server, no keys, no uploads. Source: demo/ in the repo.
